# ML пайплайн Nexus

В этой папке живут все скрипты, связанные с обучением и проверкой моделей.

- `train.py` — точка входа для обучения / дообучения модели.
- `test_model.py` — быстрый sanity-check для уже обученной модели.
- `artifacts/` — директория, куда сохраняются веса/метаданные (создаётся автоматически).

## Запуск обучения

```bash
python -m ml.train
```

После завершения в `ml/artifacts/model_stub.json` появится файл с артефактом.

## Проверка модели

```bash
python -m ml.test_model
```
