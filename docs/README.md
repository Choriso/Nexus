# Nexus — Personality-Driven Social Intelligence Platform

**Nexus** — это инновационная социальная платформа, построенная на стыке психологии и анализа данных. Проект использует теорию черт личности (**Big Five / OCEAN**) для глубокого понимания пользователей и построения интеллектуальных социальных связей[cite: 6].

## Основные возможности
*   **AI Profiling**: Автоматическое извлечение психологического профиля (OCEAN) и типа личности (MBTI) непосредственно из текстовой активности пользователя[cite: 6].
*   **Graph-Based Connections**: Использование архитектуры связей для анализа социальной совместимости и поиска наиболее подходящих партнеров или коллег[cite: 6].
*   **Communication Insights**: Оценка стиля общения, включая уровень формальности, энтузиазма и ориентации на детали[cite: 6].
*   **Advanced Compatibility**: Математический расчет совместимости на основе многомерных психологических портретов[cite: 6].

## Точность и обучение модели
Текущая версия AI-профайлера демонстрирует высокую стабильность предсказаний благодаря исправленной архитектуре ординальной регрессии[cite: 6, 7].

*   **R² Score**: 0.68 (усредненный показатель по всем пяти осям OCEAN)[cite: 7].
*   **MAE (Mean Absolute Error)**: ~0.09 (средняя ошибка предсказания составляет менее 10% от шкалы)[cite: 7].
*   **Dataset**: Модель обучена и валидирована на корпусе данных из 1726 примеров с использованием семантических эмбеддингов SBERT[cite: 6, 7].

## Технологический стек
*   **Backend**: Python, Flask, Celery[cite: 6].
*   **Machine Learning**: 
    *   `SentenceTransformer` (SBERT) для генерации семантических векторов[cite: 6].
    *   `PyTorch`: кастомная модель `PersonalityClassifier` с использованием Residual Blocks для борьбы с затуханием градиента[cite: 6].
    *   Уникальная лосс-функция для ординальной классификации, оптимизирующая предсказание интервалов[cite: 7].
*   **Database**: Поддержка PostgreSQL и SQLite через единую прослойку абстракции данных[cite: 6].
*   **Asynchronous Tasks**: Redis в качестве брокера сообщений для обработки тяжелых лингвистических вычислений[cite: 6].

## Архитектура ML-модуля
Система анализирует не только смысл слов (через эмбеддинги), но и мета-параметры текста: длину сообщений, использование регистра, пунктуацию и эмоциональные маркеры[cite: 6]. Это позволяет различать "профессиональный" и "дружелюбный" стили общения даже при схожем содержании[cite: 6].

Интеграция OCEAN и MBTI происходит через взвешенное смешивание (Neural Blend), где при отсутствии прямой MBTI-модели система автоматически полагается на высокоточный OCEAN-профиль[cite: 6].
