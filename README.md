# Nexus — Personality-Driven Social Intelligence Platform

**Nexus** — это инновационная социальная платформа, построенная на стыке психологии и анализа данных. Проект использует теорию черт личности (**Big Five / OCEAN**) для глубокого понимания пользователей и построения интеллектуальных социальных связей.

## Основные возможности
*   **AI Profiling**: Автоматическое извлечение психологического профиля (OCEAN) и типа личности (MBTI) непосредственно из текстовой активности пользователя.
*   **Graph-Based Connections**: Использование архитектуры связей для анализа социальной совместимости и поиска наиболее подходящих партнеров или коллег.
*   **Communication Insights**: Оценка стиля общения, включая уровень формальности, энтузиазма и ориентации на детали.
*   **Advanced Compatibility**: Математический расчет совместимости на основе многомерных психологических портретов.

## Точность и обучение модели
Текущая версия AI-профайлера демонстрирует высокую стабильность предсказаний благодаря исправленной архитектуре ординальной регрессии.

*   **R² Score**: 0.68 (усредненный показатель по всем пяти осям OCEAN).
*   **MAE (Mean Absolute Error)**: ~0.09 (средняя ошибка предсказания составляет менее 10% от шкалы).
*   **Dataset**: Модель обучена и валидирована на корпусе данных из 1726 примеров с использованием семантических эмбеддингов SBERT.

## Технологический стек
*   **Backend**: Python, Flask, Celery .
*   **Machine Learning**: 
    *   `SentenceTransformer` (SBERT) для генерации семантических векторов.
    *   `PyTorch`: кастомная модель `PersonalityClassifier` с использованием Residual Blocks для борьбы с затуханием градиента.
    *   Уникальная лосс-функция для ординальной классификации, оптимизирующая предсказание интервалов.
*   **Database**: Поддержка PostgreSQL и SQLite через единую прослойку абстракции данных.
*   **Asynchronous Tasks**: Redis в качестве брокера сообщений для обработки тяжелых лингвистических вычислений.

## Архитектура ML-модуля
Система анализирует не только смысл слов (через эмбеддинги), но и мета-параметры текста: длину сообщений, использование регистра, пунктуацию и эмоциональные маркеры. Это позволяет различать "профессиональный" и "дружелюбный" стили общения даже при схожем содержании.

Интеграция OCEAN и MBTI происходит через взвешенное смешивание (Neural Blend), где при отсутствии прямой MBTI-модели система автоматически полагается на высокоточный OCEAN-профиль.
